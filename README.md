# **DpS - Dungeons per Second**
## Projeto de Software - Técnico em Informática Integrado

Dungeons per Second é um jogo do gênero *Roguelite*, com arte em estilo *pixel art* 2D,
focado na simplicidade mecânica e rejogabilidade, onde o jogador deve atravessar masmorras
geradas proceduralmente, com o objetivo de obter a maior pontuação e menor tempo.
